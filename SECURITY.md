
# Security Policy

## Security Overview

HostelXchange takes the security and privacy of its
users seriously.

We aim to protect user accounts, personal information,
product listings, and transactions from unauthorized
access and misuse.

## Supported Versions

Currently, only the latest version of HostelXchange
is supported with security updates.

| Version | Supported |
|---------|-----------|
| Latest  | Yes       |
| Older versions | No |

## Reporting a Vulnerability

If you discover a security vulnerability in HostelXchange,
please report it responsibly.

Please do not disclose security vulnerabilities publicly
through GitHub Issues or Pull Requests.

Instead, use GitHub's private vulnerability reporting
feature if it is enabled for this repository.

When reporting a vulnerability, include:

- Description of the vulnerability.
- Steps to reproduce the issue.
- Potential security impact.
- Screenshots or relevant technical details, if available.

## Security Areas

We particularly welcome reports involving:

- Authentication and authorization.
- User data privacy.
- API security.
- Database access.
- Unauthorized product or transaction modifications.
- Cross-site scripting (XSS).
- Other security vulnerabilities.

## Responsible Disclosure

Please allow the project maintainers reasonable time
to investigate and address reported vulnerabilities
before publicly disclosing them.

Thank you for helping keep HostelXchange secure.
